# Beyond Version Control: GitHub Actions for Power BI Development

# Description:
🚀 Ready to take your Power BI development process beyond basic version control?

Are you already working with PBIP and TMDL and have experience using version control in Power BI? This session shows how to go further by automating code quality checks, testing, and deployment, all while keeping full control over changes.

In this session, we explore Power BI integration with GitHub and GitHub Actions for developers who want to move away from manual processes and adopt CI/CD automation.

🔹 You will learn how to automate workflows for Power BI Project files to improve collaboration and governance.
🔹 You will see how GitHub Actions can be used to enforce best practices through automated code reviews, consistent formatting, and the Best Practice Analyzer.
🔹 We will cover how to manage Pull Request approvals in a way that streamlines development without introducing unnecessary automation complexity.

The session includes hands-on examples and a live demo, offering practical and actionable steps to integrate automation into your Power BI development workflow.

A basic understanding of GitHub terminology such as branch, commit, and Pull Request, as well as familiarity with PBIP, is required.

🎯 Level: Intermediate
